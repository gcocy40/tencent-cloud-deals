## 常见问题

**免费试用和首单优惠能同时用吗？**
能。试用占的是试用名额，首单优惠是购买资格，两者互不影响。先试用再买是标准操作。

**代金券能叠加活动价吗？**
不能。代金券只能在正价购买或续费时抵扣，活动页里的秒杀价、买赠价都用不了。

**秒杀抢不到怎么办？**
买 99 元/年的 OpenClaw，配置和 38 元秒杀一样，都是 4核4G/3M/40G/300G。

**同价续费能一直续下去吗？**
不能，每个配置限 1 次。新购 1 次加续费 1 次，两年后恢复原价。

**买 1 年送 3 个月是所有套餐都有吗？**
只有买赠专区。秒杀、OpenClaw、服务器专区不送。

**38 元秒杀企业账号能买吗？**
不能。38 元秒杀是个人专享，企业账号只能买 99 元 OpenClaw 或服务器专区。

**轻量应用服务器和 CVM 怎么选？**
轻量是打包套餐，CPU、内存、带宽、流量、系统盘一口价，适合个人博客、小程序后端和快速上线；CVM 配置可自定义、扩展性强，适合业务复杂的团队。新用户先用轻量，业务起来再考虑 CVM，CVM 也有独立的首单优惠。
